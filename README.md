# StudyNotes 11 & 12

Simple, structured Class 11 & Class 12 study guides for **Physics, Chemistry, Biology, and Mathematics**, built with Next.js (App Router, TypeScript, Tailwind CSS).

## Features

- **Landing Page (`/`)** — Overview of all 4 core subjects with direct links to filtered topics.
- **Topics Selector (`/topics`)** — Filter by subject, Class 11 / Class 12, or search by keyword; clicking any topic opens its study guide in a new page.
- **Study Guide Pages (`/notes/[subject]/[slug]`)** — Clean print-ready notes with structured sections, worked examples, summary tables, formulas, and embedded PDF support.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
